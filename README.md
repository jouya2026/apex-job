# Apex Job — راهنمای راه‌اندازی

سایت + اپلیکیشن اندروید + داشبورد تبلیغات. وظایف هر ۲ ساعت به‌صورت خودکار جمع‌آوری می‌شوند و شما هیچ کاری برای نشر آن‌ها انجام نمی‌دهید.

```
GitHub Actions (هر ۲ ساعت) ──► Supabase (دیتابیس) ◄── سایت (GitHub Pages)
        │                              ▲                └── اپ اندروید (APK)
        └─ ساخت APK و سایت             └── داشبورد مدیریت: admin.html
```

---

## مرحله ۱ — Supabase (دیتابیس رایگان) — حدود ۵ دقیقه

1. در [supabase.com](https://supabase.com) ثبت‌نام کنید و **New project** بسازید (Region: Frankfurt).
2. فایل `supabase/schema.sql` را باز کنید، در **آخرین خط** ایمیل خود را به جای `YOUR-EMAIL@example.com` بنویسید.
3. در Supabase بروید به **SQL Editor** ← محتوای کامل فایل را بچسبانید ← **Run**.
4. بروید به **Authentication ← Users ← Add user ← Create new user**؛ همان ایمیل و یک رمز بنویسید و تیک **Auto Confirm User** را بزنید. (این حساب ورود شما به داشبورد تبلیغات است.)
5. بروید به **Project Settings ← API Keys** و این سه مقدار را کاپی کنید:
   - **Project URL**
   - **Publishable key** (یا در پروژه‌های قدیمی‌تر: `anon public`)
   - **Secret key** (یا: `service_role`) — این کلید محرمانه است.

## مرحله ۲ — GitHub — حدود ۱۰ دقیقه

1. یک ریپازیتوری **Public** به نام `apex-job` بسازید.
2. همه فایل‌های این پوشه را آپلود کنید (پوشه `.github` حتماً باید آپلود شود). ساده‌ترین راه با Git:
   ```bash
   cd apex-job
   git init && git add . && git commit -m "Apex Job"
   git branch -M main
   git remote add origin https://github.com/USERNAME/apex-job.git
   git push -u origin main
   ```
3. **Settings ← Secrets and variables ← Actions ← New repository secret** و این‌ها را اضافه کنید:

   | نام Secret | مقدار |
   |---|---|
   | `SUPABASE_URL` | Project URL |
   | `SUPABASE_PUBLISHABLE_KEY` | Publishable key |
   | `SUPABASE_SECRET_KEY` | Secret key |
   | `ANDROID_KEYSTORE_PASSWORD` | از فایل `android-signing-SECRET.txt` |
   | `ANDROID_KEYSTORE_BASE64` | از فایل `android-signing-SECRET.txt` |

4. **Settings ← Pages ← Source** را روی **GitHub Actions** بگذارید.

## مرحله ۳ — روشن کردن

در زبانه **Actions**:
1. ورک‌فلو **«جمع‌آوری خودکار وظایف»** ← **Run workflow** (اولین اجرا چند دقیقه طول می‌کشد).
2. ورک‌فلو **«انتشار سایت»** و **«ساخت اپلیکیشن اندروید»** ← **Run workflow**.

نتیجه:
- سایت: `https://USERNAME.github.io/apex-job/`
- داشبورد تبلیغات: `https://USERNAME.github.io/apex-job/admin.html`
- فایل APK: صفحه **Releases** ریپازیتوری (لینک دانلود در خود سایت هم نمایش داده می‌شود)

از این به بعد همه‌چیز خودکار است: هر ۲ ساعت وظایف تازه، هر بار که فایلی را تغییر دهید سایت و APK دوباره ساخته می‌شوند.

## مرحله ۴ — آدرس دفتر و اوقات کاری

پس از ورود به پنل مدیریت (`admin.html`) در بخش **«تنظیمات تماس»** آدرس دفتر، اوقات کاری، پاسخ «هزینه خدمات» و شماره‌ها را به سه زبان بنویسید و ذخیره کنید. این معلومات فوراً در سایت و اپ نمایش داده می‌شود و به ساختن دوباره APK نیاز ندارد.

## به‌روزرسانی نسخه ۲ (اگر نسخه اول را قبلاً نصب کرده‌اید)

1. فایل `supabase/update-v2.sql` را یک‌بار در Supabase → SQL Editor اجرا کنید.
2. همه فایل‌های پروژه را با فایل‌های تازه جایگزین و در GitHub آپلود (Commit) کنید. سایت و APK خودکار دوباره ساخته می‌شوند.
3. APK تازه را از صفحه Releases دریافت و نصب کنید (روی نسخه قبلی نصب می‌شود).

---

## به‌روزرسانی نسخه ۳: ترجمه خودکار، PWA و آیکن تازه

1. فایل `supabase/update-v3.sql` را یک‌بار در Supabase → SQL Editor اجرا کنید.
2. فایل‌های تغییرکرده را در ریپازیتوری جایگزین و Commit کنید.
3. **ترجمه با هوش مصنوعی (پیشنهادی، رایگان، بدون کارت):**
   1. به [aistudio.google.com](https://aistudio.google.com/apikey) بروید و با حساب Gmail وارد شوید ← **Create API key**.
   2. کلید را در GitHub ← Settings ← Secrets and variables ← Actions با نام `GEMINI_API_KEY` ذخیره کنید.
   3. بدون این کلید هم ترجمه با Google Translate رایگان انجام می‌شود، ولی کیفیت ادبی آن پایین‌تر است.
4. در Actions ورک‌فلو **«جمع‌آوری خودکار وظایف»** را یک‌بار دستی اجرا کنید. هر بار ۲۵ وظیفه ترجمه می‌شود؛ وظایف موجود در چند اجرای اول (چند ساعت) همه ترجمه می‌شوند و از آن به بعد هر وظیفه تازه خودکار ترجمه می‌شود.
5. **نصب روی آیفون:** سایت را در Safari باز کنید ← دکمه شریک‌سازی ← **Add to Home Screen**. در اندروید و کمپیوتر، دکمه «نصب» در صفحه خانه نمایش داده می‌شود.

## رهنمای پنل مدیریت (`admin.html`)

پنل مدیریت روی **Supabase** کار می‌کند (نه Firebase). پلان رایگان Supabase به کارت بانکی نیاز ندارد، تصاویر GIF متحرک را می‌پذیرد و ۱ گیگابایت جای ذخیره تصویر دارد.

**ورود:** `https://USERNAME.github.io/apex-job/admin.html` ← همان ایمیل و رمزی که در Supabase → Authentication ساختید.

**۱) آگهی‌ها**
1. دکمه **«آگهی تازه»**.
2. **محل نمایش** را انتخاب کنید:
   - *اسلایدر بالای صفحه*: بنر بزرگ و چرخشی در صفحه اصلی (اندازه پیشنهادی ۱۶۰۰×۵۲۰).
   - *بنر میان وظایف*: پس از هر ۶ وظیفه در فهرست (۱۶۰۰×۴۴۰).
   - *بنر صفحه مشخصات*: داخل صفحه هر وظیفه (۱۶۰۰×۴۴۰).
   - *استیکر شناور*: یک استیکر کوچک متحرک در گوشه صفحه که کاربر می‌تواند ببندد (۴۰۰×۴۰۰).
3. **نوعیت**: «تصویر / GIF متحرک» (فایل را آپلود کنید، حداکثر ۸ مگابایت) یا «متنی متحرک» (عنوان، متن دوم، متن دکمه و رنگ‌ها؛ بدون نیاز به دیزاین).
4. **لینک هنگام کلیک** (اختیاری): مثلاً لینک واتساپ یا صفحه آگهی‌دهنده.
5. **آغاز و پایان نشر**: آگهی خودکار در همین زمان نشر و خاموش می‌شود. **اولویت** بزرگ‌تر یعنی نمایش نخست.
6. **ذخیره**. آگهی در کمتر از یک دقیقه در سایت و اپ دیده می‌شود. پیش‌نمایش زنده در سمت دیگر فورم است.
7. در فهرست آگهی‌ها می‌توانید با کلید، آگهی را خاموش/روشن، ویرایش یا حذف کنید. تعداد کلیک‌های هر آگهی هم نمایش داده می‌شود.

**۲) درخواست‌های واتساپ:** هر بار که کسی دکمه واتساپ یک وظیفه را می‌زند، این‌جا ثبت می‌شود (نام وظیفه، کد وظیفه، زبان، اپ یا سایت). با **«پاسخ‌های آماده»** جواب‌های همان وظیفه را کاپی کنید و پس از رسیدگی **«رسیدگی شد»** را بزنید.

**۳) پاسخ‌های آماده:** کد وظیفه (مثلاً `AJ-146752`) را از پیام مراجعه‌کننده کاپی کنید ← پاسخ‌های همان وظیفه به دری، پښتو یا انگلیسی ساخته می‌شود ← با یک کلیک کاپی و در واتساپ بفرستید.

**۴) تنظیمات تماس:** شماره واتساپ، تلیفون، آدرس، اوقات کاری، پاسخ هزینه خدمات و اسناد اضافی.

## واتساپ: کمترین زمان برای پاسخ

**چه چیزی خودکار است:**
- وقتی کاربر دکمه واتساپ را می‌زند، پیام آماده با نام وظیفه، ارگان، موقعیت، ختم مهلت و **کد وظیفه** (مثلاً `AJ-146752`) باز می‌شود؛ هیچ لینکی در پیام نیست.
- در صفحه هر وظیفه بخش **«پرسش‌های متداول درباره این وظیفه»** است که پاسخ‌ها را خودکار از روی همان وظیفه می‌سازد: اسناد لازم، شرایط (جنسیت، تحصیلات، تجربه، موقعیت)، ختم مهلت و روزهای باقی‌مانده، روش درخواست، زمان نتیجه، هزینه خدمات، آدرس و اوقات کاری. بیشتر مراجعه‌کنندگان جواب خود را پیش از پیام دادن می‌بینند.
- در پنل مدیریت، همین پاسخ‌ها برای هر کد وظیفه آماده کاپی است.

**تنظیم یک‌باره اپ WhatsApp Business (رایگان، بدون کارت بانکی):**
1. اپ **WhatsApp Business** را نصب و شماره `0790499585` را در آن فعال کنید.
2. **Settings ← Business tools ← Greeting message**: متن «پیام خوش‌آمد» را از پنل مدیریت (بخش پاسخ‌های آماده) کاپی کنید.
3. **Business tools ← Away message**: متن «پیام بیرون از وقت کاری» را بگذارید و اوقات کاری را تنظیم کنید.
4. **Business tools ← Quick replies**: برای هر متن یک میانبر بسازید: `/اسناد`، `/هزینه`، `/آدرس`، `/انگیزه`. هنگام گفتگو با نوشتن «/» متن کامل فوراً می‌آید.
5. **Labels**: برچسب‌هایی مثل «تازه»، «اسناد رسید»، «ارسال شد» بسازید تا کار هر مراجعه‌کننده دنبال شود.

**پاسخ کاملاً خودکار (ربات) چرا اکنون ساخته نشد:** ربات واقعی واتساپ فقط از راه WhatsApp Cloud API (شرکت Meta) ممکن است. از ۱ اکتوبر ۲۰۲۶ Meta پیام‌های پاسخ را هم پولی کرده (۱۰۰۰ پیام رایگان در ماه) و ثبت کارت بانکی را لازم دانسته است؛ علاوه بر این، شماره‌ای که به API وصل شود دیگر در اپ عادی واتساپ کار نمی‌کند. چون شرط شما «بدون کارت بانکی» بود، روش بالا انتخاب شد. هر وقت خواستید، ربات را می‌توان روی همین Supabase (Edge Functions) اضافه کرد.

## اختیاری: نوتیفیکیشن واقعی روزانه (Firebase)

Firebase فقط برای نوتیفیکیشن موبایل است و هیچ ربطی به آگهی‌ها ندارد. پلان رایگان آن (Spark) هم کارت بانکی نمی‌خواهد. بدون Firebase، اپ هر روز ساعت ۹ صبح یک یادآوری «وظایف جدید امروز» نشان می‌دهد. برای نوتیفیکیشن واقعی با تعداد وظایف جدید:
1. در [console.firebase.google.com](https://console.firebase.google.com) پروژه بسازید ← **Add app ← Android** ← Package name: `com.apexjob.app` ← فایل `google-services.json` را دانلود کنید.
2. محتوای این فایل را در Secret به نام `GOOGLE_SERVICES_JSON` بگذارید.
3. **Project settings ← Service accounts ← Generate new private key** ← محتوای فایل JSON را در Secret به نام `FIREBASE_SERVICE_ACCOUNT` بگذارید.
4. ورک‌فلو اندروید را دوباره اجرا کنید و APK جدید را نصب کنید.

## انتقال به سرور یا دامنه واقعی

- **دامنه شخصی روی همین GitHub Pages:** Settings ← Pages ← Custom domain. سپس در **Settings ← Secrets and variables ← Actions ← Variables** متغیری به نام `SITE_URL` با آدرس کامل (مثلاً `https://apexjob.af/`) بسازید.
- **هاست دیگر:** دستور `npm run build` را اجرا کنید و محتوای پوشه `dist` را روی هر هاست (cPanel, Netlify, Cloudflare Pages) آپلود کنید. Supabase و جمع‌آوری خودکار مثل قبل کار می‌کنند.

## نکات مهم

- اگر ریپازیتوری ۶۰ روز هیچ تغییری نداشته باشد، GitHub اجرای زمان‌بندی‌شده را متوقف می‌کند. با یک تغییر کوچک یا فعال کردن دوباره ورک‌فلو در Actions دوباره روشن می‌شود.
- متن خود وظایف (شرح وظایف، شرایط) به همان زبانی نمایش داده می‌شود که ارگان نوشته است؛ تمام رابط کاربری، ولایت‌ها، بخش‌ها و نوع قرارداد به سه زبان ترجمه می‌شوند.
- اگر سایت منبع ساختار صفحات خود را تغییر دهد، فایل `scraper/parse.mjs` نیاز به اصلاح دارد. نتیجه هر اجرا در Actions و در پنل مدیریت (کارت «آخرین تازه‌سازی وظایف») دیده می‌شود.
- فایل `android-signing-SECRET.txt` را هرگز در GitHub آپلود نکنید و آن را نگه دارید؛ بدون آن نسخه‌های بعدی اپ روی نسخه نصب‌شده به‌روز نمی‌شوند.
